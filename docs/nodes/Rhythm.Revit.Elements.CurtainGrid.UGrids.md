## In Depth

`CurtainGrid.UGrids(curtainGrid)`

This node will retrieve the U gridlines from the curtain grid

The inputs are:

- `curtainGrid` (_CurtainGrid_) — The curtain grid to get data from.

Returns `UGrids` (_list of Element_) — The grids in the U direction, (horizontal).

Found in the library under **Query**.

Search terms: `curtaingrid`, `rhythm`.
