## In Depth

`Ceiling.ByCurveLoops(curves, ceilingType, level)`

Create a ceiling by multiple curve loops. Revit 2022+

The inputs are:

- `curves` (_list of list of Curve_) — The input curves as a list of lists.
- `ceilingType` (_Element_) — Ceiling type to use.
- `level` (_Level_) — The level to host on.

Returns `ceiling` (_Element_) — The newly created ceiling.

Found in the library under **Actions**.
