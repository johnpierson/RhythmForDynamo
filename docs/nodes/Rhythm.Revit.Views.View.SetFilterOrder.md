## In Depth

`View.SetFilterOrder(view, viewFilters)`

Set the view filter order for the view or view template. Important: the view filters must already be assigned to the view in order to preserve overrides.

The inputs are:

- `view` (_View_) — The view or view template
- `viewFilters` (_list of Element_) — The view filters in order

Returns `viewFiltersInNewOrder` (_list of Element_).
