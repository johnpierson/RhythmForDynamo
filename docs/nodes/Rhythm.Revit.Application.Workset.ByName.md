## In Depth

`Workset.ByName(name)`

Retrieves a workset by name.

The inputs are:

- `name` (_string_) — The name of the workset to retrieve.

Returns `workset` (_Workset_) — The workset matching the given name.

Found in the library under **Query**.

Search terms: `workset`, `byname`, `find`, `workshared`, `rhythm`.
