## In Depth

`Applications.CloseDocument(document, save)`

This node will close the given document with the option to save.

The inputs are:

- `document` (_object_) — The background opened document object, (preferably this is the title as obtained with Applications.OpenDocumentFile from Rhythm).
- `save` (_boolean_) — Do you want to save?

Returns `result` (_string_) — Did it work?

Found in the library under **Actions**.

Search terms: `Application.CloseDocument`, `rhythm`.
