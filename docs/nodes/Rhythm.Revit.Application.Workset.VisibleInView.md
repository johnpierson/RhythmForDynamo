## In Depth

`Workset.VisibleInView(workset, view)`

Returns whether a workset is visible in a specific view.

The inputs are:

- `workset` (_Workset_) — The workset to query.
- `view` (_Element_) — The view to check visibility in.

Returns `visible` (_boolean_) — Whether the workset is visible in the view.

Found in the library under **Query**.
