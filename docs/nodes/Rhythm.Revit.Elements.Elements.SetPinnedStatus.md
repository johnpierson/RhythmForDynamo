## In Depth

`Elements.SetPinnedStatus(element, status)`

This node will change the pinned status of an element.

The inputs are:

- `element` (_Element_) — The element to change the status of.
- `status` (_boolean_) — The pinned status. True = pinned, False = not pinned.

Returns `element` (_Element_) — The elements.

Found in the library under **Actions**.
