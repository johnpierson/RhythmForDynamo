## In Depth

`FamilyInstances.RetrieveNestedComponents(instance)`

This node will find all deeply nested components in the given family instance.

The inputs are:

- `instance` (_FamilyInstance_) — The family instance to retrieve deep nested components from.

Returns `nestedComponents` (_list of Element_) — The nested components.
