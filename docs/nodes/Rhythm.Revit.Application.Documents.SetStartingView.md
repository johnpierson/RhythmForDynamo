## In Depth

`Documents.SetStartingView(sourceDocument, view)`

This node will set the starting view of the document, given the view element.

The inputs are:

- `sourceDocument` (_object_) — The background opened document object, (preferably this is the title as obtained with Applications.OpenDocumentFile from Rhythm).
- `view` (_Element_) — The view to set.

Returns `result` (_string_) — The result.

Found in the library under **Actions**.

Search terms: `startingView`.
