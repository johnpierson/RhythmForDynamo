## In Depth

`Dimensions.SetBelowValue(dimension, belowValue)`

This node will try to set the below value for the dimensions. This will work for either single segment dimensions or all segments of a multi-segment dimension.

The inputs are:

- `dimension` (_Dimension_) — Dimension to set
- `belowValue` (_list of string_) — Value to set.

The outputs are:

- `set` — Successfully set.
- `notSet` — Not so successfully set.

Found in the library under **Actions**.

Search terms: `dimension.SetBelowValue`.
