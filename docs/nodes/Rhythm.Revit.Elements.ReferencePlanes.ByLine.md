## In Depth

`ReferencePlanes.ByLine(curve, drawInPlan: true)`

This will create a reference plane by the given curve and the selected direction. True for plan view and false for a section parallel to the line.

The inputs are:

- `curve` (_Curve_) — The curve to use.
- `drawInPlan` (_boolean_, defaults to `true`) — Choose whether or not to draw in plan or a section view of the curve, (looking at it).

Returns `result` (_Element_).

Found in the library under **Create**.
