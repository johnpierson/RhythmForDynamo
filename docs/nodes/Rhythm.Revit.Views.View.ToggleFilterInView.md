## In Depth

`View.ToggleFilterInView(view, viewFilter, toggle)`

Revit 2021 - This attempts to enable or disable a filter for a given view.

The inputs are:

- `view` (_View_) — The view to check the filter on.
- `viewFilter` (_Element_) — The view filter to check.
- `toggle` (_boolean_) — Toggle it to enabled or disabled.

Returns nothing.
