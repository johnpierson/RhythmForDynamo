## In Depth

`FamilyInstances.ArrayInterrogator(familyInstance)`

Detect if the input family instance has arrays set to less than 1

The inputs are:

- `familyInstance` (_FamilyInstance_) — The family instance to check

The outputs are:

- `containsArraysLessThan1` — Does the instance have arrays of less than 1?
- `arrayParameters` — The parameter names of arrays (if applicable).
- `arrayValues` — The parameter values of arrays (if applicable).
