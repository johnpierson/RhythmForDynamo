## In Depth

`Helpers.UserMessage(caption, message, obj)`

This provides a user message with the option to cancel the process downstream. If no is selected the node will return null.

The inputs are:

- `caption` (_string_) — The caption for the window title.
- `message` (_string_) — The message to give the user.
- `obj` (_list of object_) — The object to passthrough.

Returns `result` (_object_) — The object.

Found in the library under **Create**.
