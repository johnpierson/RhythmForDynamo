## In Depth

`Element.AnimateTransparency(element, startPercentage, endPercentage, iterations, directoryPath, view)`

Animate the transparency of an element. This will export images of the element, then revert the element back to where it was. Inspired by the Bad Monkeys team.

The inputs are:

- `element` (_list of Element_) — The element to set transparency to.
- `startPercentage` (_integer_) — The transparency start percent.
- `endPercentage` (_integer_) — The transparency end percent.
- `iterations` (_integer_) — Numnber of images.
- `directoryPath` (_string_) — Where to save the images.
- `view` (_Element_) — View to export from.

Returns `element` (_object_) — The element.
