## In Depth

`Selection.RoomAtPoint(point, phase: Rhythm.Utilities.MiscUtils.GetNull())`

Select a room at the corresponding point in the corresponding phase.

The inputs are:

- `point` (_Point_) — The point location
- `phase` (_Element_, defaults to `Rhythm.Utilities.MiscUtils.GetNull()`) — Optional phase to search in. If empty, the last phase is used.

Returns `room` (_Element_).
