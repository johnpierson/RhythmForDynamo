## In Depth

`Leaders.SetLeaderEndPosition(leader, location)`

This will set a leader's end position. Note: Obtain the leader element from the text note with TextNote.GetLeaders

The inputs are:

- `leader` (_Leader_) — The leader to set the end position of.
- `location` (_Point_) — The new location for the leader end.

Returns nothing.

Found in the library under **Actions**.
