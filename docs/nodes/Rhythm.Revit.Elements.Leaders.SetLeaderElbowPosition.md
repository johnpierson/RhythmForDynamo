## In Depth

`Leaders.SetLeaderElbowPosition(leader, location)`

This will set a leader's elbow position. Note: Obtain the leader element from the text note with TextNote.GetLeaders

The inputs are:

- `leader` (_Leader_) — The leader to set the elbow position of.
- `location` (_Point_) — The new location for the leader elbow.

Returns nothing.

Found in the library under **Actions**.
