## In Depth

`Vector.Direction(vector)`

This will determine the vector's cardinal direction (N, S, E, W, NE, NW, SE, SW). Based on the logic from Walls.Direction.

The inputs are:

- `vector` (_Vector_) — The vector to get direction from.

Returns `direction` (_string_) — The cardinal direction.

Found in the library under **Query**.
