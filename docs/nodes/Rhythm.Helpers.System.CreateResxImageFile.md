## In Depth

`System.CreateResxImageFile(imageDirectoryPath, resxFilePath)`

Creates a .Resx (resources) file from a directory of images for a Dynamo package. This helps greatly when trying to add icons to zerotouch nodes and the like.

The inputs are:

- `imageDirectoryPath` (_string_) — The image directory path to search within.
- `resxFilePath` (_string_) — Where to write the resx file.

Returns nothing.
