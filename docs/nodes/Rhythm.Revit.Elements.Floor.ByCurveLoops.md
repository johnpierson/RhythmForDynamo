## In Depth

`Floor.ByCurveLoops(curves, floorType, level)`

Create a floor with multiple loops. Revit 2022+

The inputs are:

- `curves` (_list of list of Curve_) — The input curves as a list of lists.
- `floorType` (_FloorType_) — Floor type to use.
- `level` (_Level_) — The level to host on.

Returns `floor` (_Floor_) — The new floor.

Found in the library under **Actions**.
