## In Depth

`Rooms.ApproximateDimensions(room)`

This will return the approximate room dimensions. This is achieved by taking the longest edge and using that to derive the estimated shorter edge.

The inputs are:

- `room` (_Room_) — _Not documented yet._

The outputs are:

- `dim1` — The first dimension. (not sorted as we simply get the longest edge)
- `dim2` — The second dimension. (not sorted as we simply get the longest edge)

Found in the library under **Query**.
