## In Depth

`Sheet.GetViewportsAndViews(sheet)`

This node will obtain viewports, views and schedules from a given sheet.

The inputs are:

- `sheet` (_Sheet_) — The sheet to get viewports from.

The outputs are:

- `viewports` — The viewports on the sheet.
- `views` — The views on the sheet.
- `schedules` — The schedules on the sheet.

Found in the library under **Query**.

Search terms: `viewport`, `schedules`, `rhythm`.
