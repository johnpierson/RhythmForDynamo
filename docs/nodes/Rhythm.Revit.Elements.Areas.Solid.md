## In Depth

`Areas.Solid(area, areaHeight: 10)`

This node will retrieve the area's solid geometry.

The inputs are:

- `area` (_Element_) — The area to extract solid from.
- `areaHeight` (_number_, defaults to `10`) — A manually input area height. Default value is 10.

Returns `solid` (_Solid_) — The solid.

Found in the library under **Query**.

Search terms: `Area.Boundaries`.
