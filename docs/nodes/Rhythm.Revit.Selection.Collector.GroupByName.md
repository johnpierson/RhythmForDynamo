## In Depth

`Collector.GroupByName(name)`

Collect a detail or model group by a given name in the current model.

The inputs are:

- `name` (_string_) — The name of the group to find.

Returns `groupInstance` (_list of Element_) — The group instance(s) found in the current model.

Found in the library under **Actions**.

Search terms: `Collector.ModelGroupByName`.
