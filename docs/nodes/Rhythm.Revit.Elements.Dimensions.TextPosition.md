## In Depth

`Dimensions.TextPosition(dimension)`

This node will return the text position of the dimension. If it is a multi-segment dimension it will output all of the pieces.

The inputs are:

- `dimension` (_Dimension_) — The dimension.

Returns `texPosition` (_list of Point_) — The dimension text position.

Found in the library under **Query**.

Search terms: `dimension.TextPosition`.
