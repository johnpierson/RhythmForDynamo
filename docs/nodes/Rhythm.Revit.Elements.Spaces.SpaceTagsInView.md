## In Depth

`Spaces.SpaceTagsInView(space, view)`

Return space tags for given space in given view

The inputs are:

- `space` (_Element_) — The space to check.
- `view` (_FloorPlanView_) — The view to check in.

Returns `spaceTags` (_list of Element_) — We return a list here because a space can have more than one tag. Whether or not it should, is a different conversation.
