## In Depth

`Modify.Dasherize(str)`

Underscore separates the input words with a dash. (Eg. Some-Title) Made possible with Humanizer (https://github.com/Humanizr/Humanizer)

The inputs are:

- `str` (_string_) — The string to convert to dash separated.

Returns `str` (_string_) — The resulting words separated with dashes.

Found in the library under **Actions**.
