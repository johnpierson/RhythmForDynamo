## In Depth

`Collector.ElementsOfCategoryInDocument(document, category)`

This node will collect all elements of the given category from given document.

The inputs are:

- `document` (_object_) — The document to collect from.
- `category` (_Category_) — The category to collect.

Returns `element` (_list of Element_) — The elements.

Found in the library under **Actions**.
