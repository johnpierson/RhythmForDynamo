## In Depth

`Modify.Singularize(str)`

This will attempt to return a singular version of a word. Made possible with Humanizer (https://github.com/Humanizr/Humanizer)

The inputs are:

- `str` (_string_) — The string to singularize.

Returns `singularString` (_string_) — The string in it's singular form.

Found in the library under **Actions**.
