## In Depth

`DimensionTypes.UsesProjectSettings(dimensionType)`

Determine if the given dimension type uses project (default) settings.

The inputs are:

- `dimensionType` (_list of DimensionType_) — The dimension type the unit format options from.

Returns `bool` (_list of boolean_) — A boolean mask to filter with.

Found in the library under **Query**.

Search terms: `dimensiontype`.
