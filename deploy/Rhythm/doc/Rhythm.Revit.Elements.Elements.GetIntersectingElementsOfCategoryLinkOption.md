## In Depth

`Elements.GetIntersectingElementsOfCategoryLinkOption(element, category, sourceInstance: Rhythm.Utilities.MiscUtils.GetNull())`

This will take a given element and category and grab the intersecting elements of that category.

The inputs are:

- `element` (_Element_) — The element to run intersections against.
- `category` (_Category_) — The category to check.
- `sourceInstance` (_Element_, defaults to `Rhythm.Utilities.MiscUtils.GetNull()`) — Use this input if the elements are from a link! If they are not, leave it blank.

Returns `elements` (_list of Element_) — The intersecting elements.

Found in the library under **Query**.
