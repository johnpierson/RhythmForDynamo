## In Depth

`View.GetWorksetVisibility(view, worksetId)`

This node will supply the visibility of the given workset in given view.

The inputs are:

- `view` (_Element_) — The view to obtain workset visibility from.
- `worksetId` (_list of integer_) — The workset element id as int.

Returns `result` (_list of string_) — The workset visibility.

Search terms: `view`, `workset.Visible`.
