## In Depth

`Roofs.AddPoint(roof, point)`

This node will add a point to the given roof.

The inputs are:

- `roof` (_Element_) — The roof to add shape editing points to.
- `point` (_Point_) — The points to add.

Returns `result` (_string_) — The result..
