## In Depth

`CurtainGridLine.SkippedSegmentCurves(curtainGridLine)`

This node will retrieve the geometric skipped curve segments from the curtain wall.

The inputs are:

- `curtainGridLine` (_Element_) — The curtain gridline to get data from.

Returns `skippedSegmentCurves` (_object_) — The segments that make up the curtain grid.

Found in the library under **Query**.
