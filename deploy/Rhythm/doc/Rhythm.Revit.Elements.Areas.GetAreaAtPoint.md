## In Depth

`Areas.GetAreaAtPoint(point, areaHeight: 10)`

*BETA* This node will retrieve the area(s) at the given point. This is a VERY SLOW method using solid intersection tests. You have been warned....

The inputs are:

- `point` (_Point_) — The point to select area(s) at.
- `areaHeight` (_number_, defaults to `10`) — A manually input area height. Default value is 10.

Returns `area` (_list of Element_) — The area.

Found in the library under **Query**.

Search terms: `Area.GetAreaAtPoint`.
