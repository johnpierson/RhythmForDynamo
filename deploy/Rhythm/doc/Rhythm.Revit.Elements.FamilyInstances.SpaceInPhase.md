## In Depth

`FamilyInstances.SpaceInPhase(instance, phase)`

This node will report the space the family instance resides in, (if available).

The inputs are:

- `instance` (_Element_) — The family instance to obtain space info from.
- `phase` (_Element_) — The phase to look in.

Returns `Space` (_Element_) — The space in which the instance is located (during the last phase of the project).

Found in the library under **Query**.

Search terms: `space`, `rhythm`, `element.space`.
