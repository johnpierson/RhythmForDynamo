## In Depth

`Dimensions.SetTextLocation(dimension, locationPoint)`

This node will try to set the text location for the given dimensions. This will work for either single segment dimensions or all segments of a multi-segment dimension.

The inputs are:

- `dimension` (_Dimension_) — Dimension to set
- `locationPoint` (_list of Point_) — Value to set.

Returns nothing.

Found in the library under **Actions**.

Search terms: `dimension.SetTextLocation`.
