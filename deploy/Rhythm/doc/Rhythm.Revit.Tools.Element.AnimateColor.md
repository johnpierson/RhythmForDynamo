## In Depth

`Element.AnimateColor(element, startColor, endColor, iterations, directoryPath, view)`

Animate the color of an element. This will export images of the element, then revert the element back to where it was. Inspired by the Bad Monkeys team.

The inputs are:

- `element` (_list of Element_) — The element to set color to.
- `startColor` (_Color_) — The start color.
- `endColor` (_Color_) — The end color.
- `iterations` (_integer_) — Numnber of images.
- `directoryPath` (_string_) — Where to save the images.
- `view` (_Element_) — View to export from.

Returns `element` (_object_) — The element.

Search terms: `rhythm`.
