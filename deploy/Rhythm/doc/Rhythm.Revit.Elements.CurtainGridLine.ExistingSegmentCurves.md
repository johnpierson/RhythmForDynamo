## In Depth

`CurtainGridLine.ExistingSegmentCurves(curtainGridLine)`

This node will retrieve the geometric existing curve segments from the curtain wall.

The inputs are:

- `curtainGridLine` (_Element_) — The curtain gridline to get data from.

Returns `existingSegmentCurves` (_object_) — The segments that make up the curtain grid.

Found in the library under **Query**.

Search terms: `CurtainGridLine.ExistingSegmentCurves`, `rhythm`.
