## In Depth

`Elements.IsHiddenInView(element, view)`

This node will report whether or not the given element is hidden in given views.

The inputs are:

- `element` (_list of Element_) — The element to check.
- `view` (_View_) — The views to check in.

Returns `bool` (_list of boolean_) — Is it hidden?

Found in the library under **Query**.

Search terms: `IsVisible`.
