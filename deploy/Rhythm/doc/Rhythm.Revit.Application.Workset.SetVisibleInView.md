## In Depth

`Workset.SetVisibleInView(workset, view, visible)`

Sets workset visibility in a view.

The inputs are:

- `workset` (_Workset_) — The workset to modify visibility for.
- `view` (_Element_) — The view in which to set visibility.
- `visible` (_boolean_) — True to show the workset, false to hide it.

Returns `view` (_Element_) — The updated view.

Found in the library under **Actions**.

Search terms: `workset`, `setvisible`, `visibility`, `view`, `rhythm`.
