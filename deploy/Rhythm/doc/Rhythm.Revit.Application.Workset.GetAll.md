## In Depth

`Workset.GetAll(document: null)`

Returns all user worksets in the active document.

The inputs are:

- `document` (_Document_, defaults to `null`) — The document to retrieve worksets from. Defaults to the current document.

Returns `worksets` (_list of Workset_) — All user worksets in the document.

Found in the library under **Query**.

Search terms: `workset`, `getall`, `list`, `workshared`, `rhythm`.
