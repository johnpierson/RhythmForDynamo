## In Depth

`Rooms.RoomTagsInView(room, view)`

Return room tags for given room in given view

The inputs are:

- `room` (_Room_) — The room to check.
- `view` (_FloorPlanView_) — The view to check in.

Returns `roomTags` (_list of Element_) — We return a list here because a room can have more than one tag. Whether or not it should, is a different conversation.
