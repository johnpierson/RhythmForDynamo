## In Depth

`Modify.Pluralize(str)`

This will attempt to return a plural version of a word. Made possible with Humanizer (https://github.com/Humanizr/Humanizer)

The inputs are:

- `str` (_string_) — The string to pluralize.

Returns `pluralString` (_string_) — The string in it's plural form.

Found in the library under **Actions**.
