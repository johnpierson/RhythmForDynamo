## In Depth

`Dimensions.IsOverriden(dimension)`

This node will check if the dimension has any overrides in it of text.

The inputs are:

- `dimension` (_Dimension_) — The dimension to check

Returns `result` (_boolean_) — True = overridden with text, False = not so overridden.

Found in the library under **Query**.

Search terms: `dimension.IsOverriden`.
