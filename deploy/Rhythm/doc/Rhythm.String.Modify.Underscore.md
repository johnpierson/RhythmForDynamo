## In Depth

`Modify.Underscore(str)`

Underscore separates the input words with underscore. (Eg. some_title) Made possible with Humanizer (https://github.com/Humanizr/Humanizer)

The inputs are:

- `str` (_string_) — The string to convert to underscore separated.

Returns `str` (_string_) — The resulting words separated with underscores.

Found in the library under **Actions**.
