## In Depth

`Roofs.AddSplitLineWithElevation(roof, curve, elevation)`

This node will add a split line to the given roof with supplied line and elevation.

The inputs are:

- `roof` (_Element_) — The roof to split.
- `curve` (_Curve_) — The geometry curve to use.
- `elevation` (_number_) — The elevation to go to.

Returns `result` (_string_) — The result..

Found in the library under **Actions**.
