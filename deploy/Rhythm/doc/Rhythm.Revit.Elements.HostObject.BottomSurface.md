## In Depth

`HostObject.BottomSurface(hostObject)`

This node will return the bottom face or faces for the input host object. This particular method works for ceilings, roofs, or floors.

The inputs are:

- `hostObject` (_Element_) — The host object to retrieve bottom faces for.

Returns `result` (_list of list of Surface_).

Found in the library under **Query**.
