## In Depth

`CurtainGrid.VGrids(curtainGrid)`

This node will retrieve the V gridlines from the curtain grid

The inputs are:

- `curtainGrid` (_CurtainGrid_) — The curtain grid to get data from.

Returns `VGrids` (_list of Element_) — The grids in the V direction, (horizontal).

Found in the library under **Query**.

Search terms: `curtaingrid`, `rhythm`.
