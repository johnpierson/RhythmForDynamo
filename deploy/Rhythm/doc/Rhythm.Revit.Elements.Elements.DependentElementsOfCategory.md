## In Depth

`Elements.DependentElementsOfCategory(element, category)`

This node will report what elements depend on the input element. Useful for determining safe deletion.(Available Revit 2018.1+).

The inputs are:

- `element` (_Element_) — The element to check.
- `category` (_Category_) — The category to use to filter the elements.

Returns `dependentElements` (_list of Element_) — The dependent elements.

Found in the library under **Query**.

Search terms: `DependentElements`.
