## In Depth

`FamilyInstances.RoomInPhase(instance, phase)`

This node will report the room the family instance resides in, (if available).

The inputs are:

- `instance` (_Element_) — The family instance to obtain room info from.
- `phase` (_Element_) — The room to look in.

Returns `Room` (_Element_) — The room by phase in which the instance is located.

Found in the library under **Query**.

Search terms: `space`, `rhythm`, `element.space`.
