## In Depth

`CurtainGrid.ByCurtainSystem(curtainSystem)`

This node will retrieve the curtain grid per face from the curtain system.

The inputs are:

- `curtainSystem` (_CurtainSystem_) — The curtain system to get data from.

Returns `curtainGrid` (_list of CurtainGrid_) — The internal curtain grid.

Found in the library under **Create**.

Search terms: `curtaingrid`, `rhythm`.
