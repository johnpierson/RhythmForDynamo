## In Depth

`Collector.ElementsOfTypeInDocument(document, elementType)`

This node will collect all elements of type from given document.

The inputs are:

- `document` (_object_) — The document to collect from. Preferably the document title obtained from Applications.OpenDocumentFile.
- `elementType` (_Type_) — The element type to collect.

Returns `element` (_list of Element_) — The elements.

Found in the library under **Actions**.

Search terms: `All Elements of Type in Document`.
