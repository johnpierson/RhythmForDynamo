## In Depth

`Workset.Rename(workset, newName)`

Renames an existing user workset in the active document.

The inputs are:

- `workset` (_Workset_) — The workset to rename.
- `newName` (_string_) — The new name for the workset.

Returns `workset` (_Workset_) — The renamed workset.

Found in the library under **Actions**.

Search terms: `workset`, `rename`, `workshared`, `rhythm`.
