## In Depth

`Dimensions.DisplayValueString(dimension)`

Retrieve the actual dimension display value. The built in RevitAPI method returns the string per the project setting. This returns it per the dimension setting.

The inputs are:

- `dimension` (_Dimension_) — The dimension to retrieve values from.

Returns `realValueString` (_list of string_) — The real string value for the dimension.

Found in the library under **Query**.
