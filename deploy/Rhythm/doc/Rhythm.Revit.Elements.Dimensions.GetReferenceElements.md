## In Depth

`Dimensions.GetReferenceElements(dimension)`

This node will retrieve the reference elements of the dimension. Will not work with multi segment dimensions.

The inputs are:

- `dimension` (_Dimension_) — Dimension to get elements from.

Returns `referenceElements` (_list of Element_) — The reference elements.

Found in the library under **Query**.

Search terms: `dimension.GetReferenceElements`.
